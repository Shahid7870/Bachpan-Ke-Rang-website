# Bachpan Ke Rang (बचपन के रंग) - Web Application

A full-featured, responsive React + Vite website for **Bachpan Ke Rang (BKR)**, located in Thana Chowk, Laukaha Bazaar, Madhubani, Bihar.

## Features
- **Responsive Layout**: Optimized for Mobile, Tablet, and Desktop.
- **Direct WhatsApp Ordering**: Pre-filled inquiry messages for instant customer chats.
- **Interactive Catalog**: Filter products by Boys, Girls, Footwear, and Ethnic wear.
- **Google Maps Integration**: Direct navigation to Thana Chowk Laukaha.
- **Brand Identity**: Includes logo, visiting card, carry bag showcase, and banners.

## How to Run

1. Extract the ZIP file.
2. Open terminal in the project directory:
   ```bash
   npm install
   npm run dev
   ```
3. Open `http://localhost:5173` in your browser.

## Build for Production
```bash
npm run build
```
